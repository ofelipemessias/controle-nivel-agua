# Controle de Nível de Água

Atividade da **Agenda 11 - Desenvolvimento de Sistemas I**, da ETEC.

Este projeto apresenta um exemplo de monitoramento de nível de um reservatório. O programa em Python percorre cinco níveis predefinidos e exibe cada situação com uma cor diferente no terminal, usando a biblioteca **Colorama**.

## Como executar

1. Instale a dependência: `pip install colorama`
2. Execute o programa: `python main.py`

O código demonstra o uso de listas, funções, estruturas condicionais, laços de repetição e formatação colorida da saída no terminal.
